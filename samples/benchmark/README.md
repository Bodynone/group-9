# 20 份匿名合成基准作业

`S01.txt`–`S20.txt` 是按 `samples/S1.txt`、`samples/S2.txt` 的任务单格式和项目现行 `2026-v1` 量表编制的合成需求工程作业。每份有基本信息、A–F 分节、模拟过程说明与结尾标记，正文为 1,507–2,547 字符；缺失维度保留空区标题以检验缺失识别。项目题材均是校园服务需求分析，正文中的提交对象、异常场景和编号已按各项目核对。`benchmark.json` 包含全文 SHA-256、A–F 暂定档位与分数、关键采分点及分组；标签尚未经过独立教师复核，不应称为专家真值。任何模型输入只能包含样本文本和量表，不能包含 `benchmark.json`。

在仓库根目录运行 `python backend/scripts/ablation_study.py --check` 可用标准库校验 20 份文本、哈希、档位与总分，不调用模型。三组真实模型实验的安装、运行和指标解释见 `docs/eval-report.md`。

这些 `.txt` 文件由 `.gitattributes` 固定为 LF 换行，SHA-256 对应文件的实际 UTF-8 字节。校验过程保留原文换行和 Unicode 字符，不会通过自动换行归一化使被改动的文件通过哈希检查。
