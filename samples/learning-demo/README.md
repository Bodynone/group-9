# 教学增强演示样本

所有资料与作业均为匿名合成文本。初稿刻意包含INNER JOIN、COUNT和NULL解释问题，修改稿补充规则、过程与边界。它们用于演示资料检索、审校及修改追踪，不是人工核定基准，也不能用于宣称准确率或教学效果。

启动新版前后端后运行：

```powershell
uv run --project backend python backend/scripts/learning_demo.py --seed
```

这只建立独立的演示课程、量表、任务和资料。需要真实模型生成初稿、修改稿两个待复核结果时，显式增加`--run`。重复运行使用同一幂等键，保留已有任务和历史。脚本不确认成绩、不填写人工参考、不把失败自动改为成功。

已有失败时，显式增加`--retry-failed`只对当前失败任务新增一次关联重试，不循环重发。试运行仍可能受账号TPM/RPM限流影响；全部尝试和失败保留，输出不作为效果评测。

演示位置：作业任务列表中进入“LEFT JOIN报告：资料检索、独立审校与修改对比”。任务设置看资料和策略，提交与复核看两版草稿，结果与学情看争议队列，教学评测看人工参考门禁。
