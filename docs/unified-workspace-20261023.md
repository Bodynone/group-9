# 统一教师工作台（2026-10-23）

本次在 YJ-SPEC-2.0 已实现能力上调整入口与页面职责，保留课程、标准、历史任务、批次和确认记录。没有新增模型调用或重新评分历史数据。

## 页面与操作

| 入口 | 职责与操作 |
|---|---|
| `/`、`/v2` | 相同工作台；默认显示作业任务列表，可按课程筛选、建立课程、新建本次作业任务 |
| 作业任务的“任务设置” | 保存题目、要求、参考说明与标准绑定；预览确认发布，发布后冻结；发布不调用模型 |
| 作业任务的“提交与复核” | 单份粘贴、批量TXT/MD、统一提交历史、证据定位、改档重算、确认JSON、失败重试与人工接管 |
| 作业任务的“结果与学情” | 只查看当前作业的批次、确认/临时统计、动态图表、规则薄弱项和确认项CSV |
| 评分标准库 | 从版本列表查看或编辑，右侧实时预览；保存校验后确认发布，发布版复制为新版本；归档/恢复/删除草稿放在更多管理操作 |
| `/legacy` | 旧固定量表单份、批量和班级大屏；保留旧localStorage键、原接口及历史数据；从右上角历史兼容入口进入 |

标准库仅管理可复用规则。选择查看某个版本不会更改已发布作业的绑定。任务详情持续显示本次任务名称与标准版本，表单、记录和批次以该作业为作用域；切换后清空前一个任务的页面状态。未保存的标准、任务设置、复核、待提交文本或文件在离开时提示。

## 历史记录与兼容

新增 `GET /api/v2/tasks?assignment_id=<id>&limit=20&offset=0`，v2共31条路由。`assignment_id`可省略以读取全部已绑定作业的提交摘要；limit为1–100，offset非负，不存在的作业404。返回 `{total,items}`，每项包含id、assignment_id、submission_label、status、total、created_at、rubric_version_id、replaced_by、parent_task_id、record_id，不返回原文、整份快照或评分理由。

索引查询已有tasks与task_contexts，按创建顺序倒序展示，不迁移、不改写任务JSON，也不重算分数。重试原记录保留，可勾选显示；被替换记录只读。旧固定标准、接口、原文哈希、Unicode码点引用、Decimal计分、共享并发3和不可变确认导出保持原协议。分页查询在前端自动读完，避免第21条历史记录无法找回。

兼容已有`/v2?task=<id>`深链接；任务与assignment参数不匹配时拒绝打开，无课程归属的旧记录转向`/legacy?task=<id>`。轮询组件卸载后忽略旧响应，防止回到前一个作业。
