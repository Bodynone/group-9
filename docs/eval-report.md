## 样本与真值

`samples/benchmark/S01.txt` 至 `S20.txt` 参照现有 S1/S2 的任务单结构和项目现行 `2026-v1` 量表撰写，正文为 1,507–2,547 字符，覆盖优秀标杆 3 份、中等常规 3 份、严重残缺 3 份、对抗注入 3 份、混合边界 8 份。`benchmark.json` 记录量表版本、每维暂定档位和分数、关键采分点、全文 SHA-256。优秀组总分 97–100，中等组 70–74.5，严重残缺组 45.5–48.5，对抗组 9–16.5。对抗样本自身的需求内容也有明显缺陷；不得仅因出现攻击语句就直接判零。

真值由量表规则编制，状态是 **暂定、未经独立教师复核**。正式用于“专家一致率”之前，需要至少一名未参与编写的教师逐维复核，记录争议和最终标签。评测脚本只在模型返回后读取这些标签用于校验数据完整性，模型输入不含答案。

## 实验方式与指标口径

在仓库根目录安装后端依赖并设置模型参数后运行：

```bash
uv sync --project backend
uv run --project backend python backend/scripts/ablation_study.py --check
uv run --project backend python backend/scripts/ablation_study.py --samples 20
```

直接 Prompt 只传量表与文本，不提供工具；工具辅助模式允许读取量表、定位原文、Decimal 计分，但不提供 `validate_draft`；完整模式执行现有 `AgentRunner` 的四类工具与最多两轮修正。三组使用相同模型、相同样本和同一量表。运行后本报告会自动替换成实测表格，逐样本结果保存为 `docs/eval-results.json`。

算术准确率与格式合规率以全部所选样本为分母，失败输出记为未通过。算术准确指报告总分等于六维分项之和；格式合规指 A–F 六维齐全、档位合法、理由非空、分数可解析、证据为数组。证据真实率以输出引用条数为分母，逐字引用须出现在原文；无引用时显示“无引用”。耗时包含模型与工具调用。Token 仅在提供方对所有调用都返回 `usage` 时统计。以上机械指标不等于教师评分准确率。

报告表格可直接用于汇报第 6 页；第 7 页可按三项百分比绘制三组柱状图，须标注实际样本数、模型版本、实验日期及未经教师核定的限制。
